# Credit Card Customer Insights & Analytics

## Project Overview
This project analyzes credit card customer and transaction data to understand customer behavior, spending patterns, card performance, revenue, and credit risk.

## Tools & Technologies
- SQL
- Power BI
- DAX

## Dataset
The project uses four CSV files containing customer information and credit card details, including income, occupation, card category, credit limit, transaction amount, transaction count, spending type, interest earned, credit utilization, and delinquency.

## Project Objectives
- Analyze customer demographics and spending behavior.
- Compare credit card categories and transaction performance.
- Identify spending patterns by expense type, state, and occupation.
- Analyze interest earned, annual fees, and credit utilization.
- Examine delinquency and potential credit risk.
- Present key business insights through an interactive Power BI dashboard.

## Project Workflow
1. Collect and understand the datasets.
2. Import the data into SQL.
3. Explore and prepare the data.
4. Perform SQL analysis using queries and aggregations.
5. Identify meaningful business insights.
6. Connect the data to Power BI.
7. Build an interactive dashboard.
8. Document the findings and recommendations.

## Project Status
In Progress

## Expected Outcome
To transform credit card data into meaningful insights that help understand customer behavior, evaluate card performance, and support data-driven business decisions.
